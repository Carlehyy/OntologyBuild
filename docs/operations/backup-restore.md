# 备份与恢复

生产备份至少覆盖：

- PostgreSQL；
- Neo4j；
- MinIO/对象存储；
- API Hub 独立数据目录；
- 共享 uploads；
- 服务器 `.env` 与部署所需非秘密配置；
- 当前镜像 digest/版本和 Compose 配置。

Redis 队列是否需要持久恢复取决于任务幂等与业务 RPO，必须在具体运行手册中
说明。

## 恢复演练

备份成功日志不等于可恢复。至少定期在隔离环境验证：

1. 恢复数据；
2. 运行 Alembic 到目标版本；
3. 启动 API 和 worker；
4. 校验对象附件、图关系、任务与 API Hub 配置；
5. 执行关键只读和写入旅程；
6. 记录 RPO、RTO 和失败项。

具体存储命令依赖生产供应商，补充前不得在文档中假设某一云平台。
