# 前端视觉设计约束

## Design Tokens

### 色彩
- 整体基调：浅色系，通透、呼吸感
- 主色：柔和的晴空蓝 (#3B82F6 系列)，用于主按钮、高亮
- 辅色：薄荷青 (#5EEAD4)、柔金 (#FCD34D)、珊瑚橙 (#FDBA74)、薰衣草紫 (#C4B5FD)、灰石 (#94A3B8)
- 卡片底色：`rgba(255, 255, 255, 0.65)` - 毛玻璃半透明白
- 页面背景：极浅的灰白渐变 + 柔和彩色光晕装饰
- 文字层级：深灰 `#1E293B`（主标题）、中灰 `#64748B`（正文）、浅灰 `#94A3B8`（辅助）
- 边框：`rgba(255,255,255,0.8)` 与 `rgba(148,163,184,0.18)` 叠加的玻璃边

### 质感（核心）
- 悬浮卡片（Glassmorphism）：`backdrop-blur-xl bg-white/65 border border-white/70 shadow-[0_8px_32px_rgba(15,23,42,0.06)]`
- 卡片 hover：轻微上移 `hover:-translate-y-0.5`，阴影加深，边框高亮
- 柔和圆角：卡片 `rounded-2xl`，输入框/按钮 `rounded-xl`，标签 `rounded-full`
- 装饰光斑：页面四角用 radial-gradient 渲染几处柔色光晕（低饱和、低透明度），营造"空气感"

### 字体
- 字体族：系统无衬线（Inter / 思源黑体 fallback）
- 标题：字重 600，大号数字用 tabular-nums 保证等宽
- 正文：14px，行高 1.6
- 辅助：12-13px，颜色浅灰

### 间距与呼吸感
- 区块间距 `gap-6`，卡片内边距 `p-6`
- 统计指标卡片留白 `p-6`，数字与标签间 `mt-1.5`
- 列表行高加大：行内 padding `py-4`，行距宽松
- 全局页面边距保持既有 Layout 的 p-6

### 动效
- 过渡：`transition-all duration-300 ease-[cubic-bezier(0.4,0,0.2,1)]`
- hover 时卡片轻微上浮 + 阴影扩散
- 图表入场使用 ECharts 的渐入动画

### 组件规范
- 主按钮：白底毛玻璃 + 蓝色强调边框/渐变文字，或实色浅蓝背景
- 次按钮：半透明白底 + 细边框
- 搜索框/筛选器：毛玻璃底，聚焦时边框变蓝、阴影柔和
- 标签：圆角 pill，背景色对应 severity 的浅色柔色 + 色点
- ECharts：去掉深色边框，轴线/刻度浅灰，使用渐变填充的面积/环形图，配色与辅色一致

### 设计禁忌
- 禁止深色背景、黑色边框、厚重阴影
- 禁止信息密度过高（行高太小、字号小于 12px、一屏塞太多字段）
- 禁止高饱和纯色直接铺底（所有颜色需降低饱和度或加透明度）
- 禁止生硬的直角分割线（使用柔边、留白代替）
